# Iris Flower Classification App

This is a Streamlit app that uses the K-Nearest Neighbors (KNN) algorithm to classify Iris flowers based on their measurements.

## Features

- User-friendly interface for predicting the flower species based on Sepal and Petal features.
- Displays the predicted class with an image of the flower.
- Shows the model's accuracy and confusion matrix.
